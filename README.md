# nslookup

A Cloudflare Workers project for DNS lookups.

## Deploy

You can deploy this project to your own Cloudflare account with a single click:

[![Deploy to Cloudflare Workers](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=https://github.com/itzemoji/nslookup)

## Manual Deployment

To manually deploy the project using Wrangler:

1. Install dependencies (if any)
2. Run `npx wrangler deploy`

## Development

To run the worker locally:

```bash
npx wrangler dev
```
