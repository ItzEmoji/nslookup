API Reference

An advanced, interactive playground to test and integrate nslookup endpoints.

GET/{domain}

Full DNS + WHOIS lookup. Returns all DNS records and optional WHOIS/RDAP data in a single JSON response.

Check if a domain or IP is blacklisted on Spamhaus. Returns true or false.
