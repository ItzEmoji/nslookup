About lookup

lookup is an advanced, privacy-friendly DNS and WHOIS lookup service. It supports querying multiple DNS resolvers in parallel, filtering record types, and returning perfectly formatted JSON for scripts.

  • Settings: Use the web UI to configure custom DNS resolvers, change the default records (A, AAAA, MX, etc.), and customize your theme.
  • Privacy: Absolutely zero tracking or logging.
  • Speed: Parallel DNS resolution via Edge Workers.
GETFull Lookup
curl {{ORIGIN}}/example.com

Gets DNS records and WHOIS data in one JSON payload.

GETSpecific Records
curl "{{ORIGIN}}/example.com?type=TXT,MX"

Filters to just the DNS records you want.

GETIP Addresses (JSON)
curl {{ORIGIN}}/ip/example.com

Returns JSON with both IPv4 and IPv6 addresses.

GETRaw IPv4
curl {{ORIGIN}}/ipv4/example.com

Returns just the raw IPv4 string. Perfect for scripting.

GETRaw IPv6
curl {{ORIGIN}}/ipv6/example.com

Returns just the raw IPv6 string.

GETWHOIS Only
curl {{ORIGIN}}/whois/example.com

Returns pure JSON RDAP/WHOIS data.

GETYour Own IP
curl {{ORIGIN}}/

Returns the IP address you are calling from.
