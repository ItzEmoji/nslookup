CLI reference

Every URL the web app uses also answers curl, with JSON or plain text. The examples use this deployment's address, so they can be pasted as they are.

Quick start

A full lookup, a single address for scripts, and the address you are calling from.

$curl {{ORIGIN}}/example.com
$curl {{ORIGIN}}/ipv4/example.com
$curl {{ORIGIN}}/

Endpoints

All endpoints are GET. Replace {domain} with a domain name and {ip} with an IPv4 or IPv6 address.

Endpoints
EndpointReturnsExample
GET/Your IP address, as plain text.
GET/{domain}All DNS records from every resolver, with a per-type consensus, propagation, Spamhaus and WHOIS status.
GET/{ip}Reverse (PTR) lookup.
GET/ip/{domain}IPv4 and IPv6 addresses as JSON.
GET/ipv4/{domain}The first IPv4 address, as plain text.
GET/ipv6/{domain}The first IPv6 address, as plain text.
GET/whois/{domain}Raw RDAP data.
GET/abuse/{domain-or-ip}true if listed on Spamhaus.
GET/propagated/{domain}true if all resolvers agree.
GET/ssl/{domain}Certificate history from Certificate Transparency logs.
GET/security/{domain}SPF, DMARC and CAA records.
GET/openapi.jsonOpenAPI 3.1 description of every endpoint, with this deployment as its server.

Query parameters

Add them to the URL. Quote the URL in your shell when it contains ? or &.

Query parameters
ParameterEndpointsEffect
type=TXT,MX/{domain}Only these record types.
whois=false/{domain}Skip the WHOIS lookup.
resolvers=<url>,<url>allQuery your own DNS-over-HTTPS resolvers instead of Cloudflare and Google.
previewallPretty-print JSON.
provider=crt.sh/ssl/{domain}Use crt.sh instead of CertSpotter.
dkim=<selector>,…/security/{domain}Also look up DKIM keys for these selectors.
$curl "{{ORIGIN}}/example.com?type=TXT,MX&preview"

Browsers and clients

Browser page navigations get the web app. Every other request gets the API, so HTTP libraries, Postman and generated clients work without extra headers.

Import /openapi.json into Postman, Insomnia or Bruno, or generate a client from it. curl {{ORIGIN}}/help prints this reference as plain text.

$curl -o openapi.json {{ORIGIN}}/openapi.json
